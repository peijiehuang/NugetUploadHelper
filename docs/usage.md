# NuGet 上传助手 · v0.0.1 使用说明

项目主页：https://github.com/peijiehuang/NugetUploadHelper

## 运行与配置

Windows 10/11 x64。发布版自带 .NET 运行环境，无需安装 SDK。把程序放到可写目录后运行。

1. 填写实际仓库地址。地址为空时显示 `http://nexus.example.com:8081/repository/nuget-hosted/` 示例提示；示例不会作为真实输入保存或自动连接。
2. 选择 **API Key** 并填写密钥，或选择 **账号密码** 并填写具有发布权限的账号。API Key 模式仅传递密钥；账号模式使用 HTTP Basic 凭据，不自动切换认证方式。
3. 点击 **保存配置**，把仓库地址、两种认证字段、当前认证方式及最近目录写入程序目录的 `settings.json`，下次启动自动读取。程序目录不可写或配置损坏时会明确报错。

配置和密码以明文保存，账号密码模式下密码也以明文显示。请保管好程序目录，不要向公开仓库或 Issue 上传实际配置、凭据与业务包。远程连接建议使用 HTTPS。

## 导入与上传

1. 使用 **添加文件**、**选择文件夹** 或拖放导入普通 `.nupkg`。文件夹只读取顶层；相同完整路径只添加一次。添加文件后再次保存配置可记住最近目录。
2. 点击 **刷新服务器信息**，按包内部 ID 读取远端版本、最新版本发布时间及版本比对结果。刷新读取列表内所有包，不受上传勾选影响，同一 ID 只查询一次。
3. 勾选需要上传的包，点击 **开始上传**。包列表左上角可以全选/取消全选；**移除**删除勾选项。
4. 单包默认超时 300 秒，失败后继续下一包。失败原因显示在日志中，也可将鼠标移到对应行或双击上传状态查看。再次上传需要重新勾选失败项；成功项不会自动取消勾选。
5. **停止后续上传**等待当前包结束后停止，剩余包保持待上传。上传中关闭窗口时，可以选择当前包完成后关闭。

支持 HTTP/HTTPS V2 Nexus 地址及 NuGet V3 `index.json` 地址。仅上传普通包，不发布 `.snupkg` 或 `.symbols.nupkg`。

重复版本由仓库决定是否允许，工具显示服务器错误，不把重复当作成功。超时不代表服务器必定未接收文件，重试前请核对仓库。真实 Nexus 的账号权限、认证和服务端配置需在目标环境验证。

## 服务器版本比对

- 按 NuGet 版本规则比较，包含预发布版本；显示“同版本已存在”“本地版本较新”“本地版本较旧”或“服务器无此包”。查询失败显示“查询失败/无法比对”，不会当作无包。
- “上传/发布时间”取服务器 NuGet 元数据中的 `Published`，对应服务器最新版本，按本机时区显示。服务器未提供时间时显示“服务器未提供”。悬停行可查看服务器版本列表和各版本时间。
- 每次刷新绕过旧缓存。修改仓库或认证信息后，旧结果清除。上传成功后标记为待刷新，可再次查询实际状态。
- 每个包 ID 查询默认超时 30 秒。刷新时底部按钮变为 **取消刷新**，可取消只读查询；查询失败不阻止手动上传。
- 推送权限与元数据读取权限可能不同。遇到 401/403，请使用具有读取权限的认证信息后重试；软件不会自动尝试另一种认证。
